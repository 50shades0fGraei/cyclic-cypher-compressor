Phase 1

On Your Windows PC

1
Download Ubuntu ARM64 ISO
You need the ARM64 version specifically — the standard x86 ISO will not boot on the Snapdragon.
🔗 Go to https://cdimage.ubuntu.com/releases/24.04/release/ → download ubuntu-24.04.x-live-server-arm64.iso
2
Flash USB with Rufus
Open Rufus, select your USB drive, point it at the ARM64 ISO, and click START. Rufus will wipe and format automatically.
⚠️ Rufus will erase everything on the USB — make sure there's nothing important on it first.
3
Copy Build Files to USB
After Rufus finishes, the USB will appear in Windows Explorer. Copy the entire project folder onto it.
robocopy "C:\Users\randall\cyclic-cypher-compressor" "E:\sovereign-build" /E /NFL /NDL (Replace E: with your actual USB drive letter)
Phase 2

On The EliteBook — Boot from USB

4
Enter Boot Menu (F9)
Plug USB into the EliteBook. Power it on and immediately press F9 repeatedly to open the boot device menu. Select your USB drive.
💡 If F9 doesn't work, try F12 or Esc. You may also need to disable Secure Boot in BIOS (F10 at startup → Security → Secure Boot → Disable).
5
Partition the NVMe Drive
Once booted into the live Ubuntu environment, open a terminal and partition the EliteBook's NVMe drive.
Partition Size Type Label Role
nvme0n1p1 512 MB vfat / FAT32 ESP EFI System Partition
nvme0n1p2 50 GB+ ext4 ROOT Tesseract-OS Root
nvme0n1p3 Remaining ext4 VAULT Sovereign DNA Vault
sudo fdisk /dev/nvme0n1 # Press g → create GPT table # Press n → create each partition # Press t → set type (1 = EFI for p1) # Press w → write and exit
Phase 3

Run The Installer

6
Navigate to Build Files on USB
In the Ubuntu live terminal, find where the USB is mounted and navigate to the build folder.
ls /media # or check /mnt — USB should auto-mount here cd /media/ubuntu/sovereign-build # adjust path to match your USB label
7
Run install-bare-metal.sh
This is the main installer. It formats partitions, installs ARM64 Linux, deploys the full Tesseract-OS stack, and registers the UEFI boot entry.
sudo bash EliteBook-Sovereign-Build/install-bare-metal.sh \ /dev/nvme0n1p1 \ /dev/nvme0n1p2 \ /dev/nvme0n1p3
⏱️ This will take 10–20 minutes. It will ask you to confirm before formatting — type y and press Enter.
8
Remove USB and Reboot
When the installer completes, power off, remove the USB, and power back on. The EliteBook will boot directly into Tesseract-OS.
sudo poweroff # Remove USB → Power on → CyberDNA-Tesseract-OS boots
